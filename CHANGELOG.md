- `colmap_stage.run_poses` takes the frame cap as `max_frames` (default 16, unchanged). `None` or `0` omits ffmpeg `-frames:v`, because `-frames:v 0` would write no frames. `fps` `None` or `0` omits the `fps` filter, because `fps=0` is not a valid filter. Both together extract every decoded frame; leaving `fps` at 1 still keeps one frame per second. `python -m sceneagent` forwards `--fps` and `--max-frames` on an mp4, with those defaults. After the extract, each image is scaled on its own by a diagonal per-channel gain (`ingest_assets.apply_per_image_color_calibration`). The target is named `per_channel_median_of_set`; `color_calibration.json` records that name, the three target values, and each image name mapped to `[gR, gG, gB]` in `gains_by_image` (the applied gains). It also records `raw_gain_rgb` (the pre-clamp triple; JSON null when that channel's mean is non-positive and the gain is uncomputable), `clamped` (true when any finite channel was clamped), `clamped_channels` (that fact per channel), `clamped_images` (those image names), and `uncomputable_channels` (image name to the channel names `red`, `green`, or `blue` whose means are non-positive; images with none are omitted). A non-positive mean keeps applied gain 1 and is not a clamp, so it is not added to `clamped_images`. Non-finite means are rejected. Finite gains outside `[0.05, 8.0]` are clamped.
